## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/rupeshsah86/PortFolio.git
cd PortFolio/nextjs-portfolio

# Install dependencies
npm install

# Run locally
npm run dev

# Build for production
npm run build
```
